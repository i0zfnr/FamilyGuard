# Liquid Glass Design System & Engineering Guide (Local Skill Copy)
Original path: C:\Users\ipan\.gemini\config\plugins\pro-design-rules\skills\liquid-glass\SKILL.md

Core Methodology:
1. Glass is a Platter, Not a Wrapper: Floating chrome and navigation platters hover above content; data cards and body copy use solid high-contrast surfaces (#111827).
2. NEVER Nest Refractive Glass Inside Refractive Glass.
3. Physics-Informed Optics: Snell's law refraction, curvature dome normals, specular rim inner highlights (inset 0 1px 1.5px rgba(255,255,255,0.45)), and 140%-180% saturation boost.
4. Accessibility: WCAG AA (>= 4.5:1 text, >= 3:1 graphics), fallbacks for prefers-reduced-transparency and prefers-reduced-motion.
